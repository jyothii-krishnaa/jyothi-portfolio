# Jyothi Krishna — Portfolio

A clean React/Vite portfolio for a Senior Backend Engineer with a growing focus on Generative AI.

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL printed by Vite.

## First edits

Open `src/main.jsx` and replace:
- `YOUR_EMAIL@example.com`
- `https://www.linkedin.com/in/YOUR_LINKEDIN`
- `https://github.com/YOUR_GITHUB`
